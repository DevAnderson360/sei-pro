Importar meus projetos do servidor do Atividades (o link de importar só aparece para quem tem servidor do Atividades configurado)
Decisões embutidas aqui (corrija o que não fizer sentido):
• “Fase” substitui “Macroetapa” (mesmo papel: agrupa as etapas no Gantt). O campo “Grupo” do legado vira etiqueta na importação, para não haver dois agrupamentos parecidos.
• “Tipo de projeto” do legado também vira etiqueta do projeto (filtrável na visão “Todos”), em vez de um campo próprio.
• “Só eu” vale para a unidade em que o projeto foi criado, como as listas dos Favoritos; o arquivo JSON leva tudo.
• Iniciar execução some como passo: a etapa entra “em andamento” sozinha quando chega a data de início (ou ao mexer no progresso). A barra de execução separada do legado vira a linha de base: o planejado original fica guardado e a barra mostra o real.
• Na Tela 1, o menu “⋯” ganha “Mostrar lista de etapas” (ligado por padrão), como você pediu.
