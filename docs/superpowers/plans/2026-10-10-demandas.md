# Gestor de Demandas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar o Gestor de Demandas (criar demanda, atribuir a responsável, visões Tabela, Quadro e Cronograma, painel de estatísticas) como pacote TypeScript `demandas/` do SEI Pro, sem backend, guardando em `chrome.storage.local`, em Textos Padrão separados por tabela e em arquivo JSON local.

**Architecture:** Pacote novo `demandas/` no molde de `historico/` e `projetos/`, sobre `sei-comum` (UI, motor de Texto Padrão, mesclagem por entidade, arquivo, cópias) e `sei-nucleo`. Três tabelas de Texto Padrão (`d` demandas ativas, `a` arquivadas, `h` histórico), cada uma com seu motor, teto e status; o orquestrador roda os motores e uma tabela que falha não bloqueia as outras. Código genérico do Projetos (Gantt, calendário, memória de sigilo, lista de responsáveis, tipos) entra por alias `@projetos/*`, como o Histórico faz com `@favoritos/*`.

**Tech Stack:** TypeScript 5.9 (strict), esbuild, tsx + linkedom (harness `verificar-*.ts` caseiro), biome, Frappe Gantt vendorizada do Projetos, File System Access API, `CompressionStream`.

**Spec:** `docs/superpowers/specs/2026-10-10-demandas-design.md`. Inventário e roteiro do legado: `docs/superpowers/specs/2026-10-10-demandas-mapa-gestor-atividades.md`. Ler os dois antes de começar.

## Global Constraints

Valem para toda tarefa (copiadas do spec e das regras duras do projeto):

- Português do Brasil em código, comentários, mensagens de interface e commits; identificadores em português; nomes de arquivo sem acento; título de commit sem acento.
- **DOM seguro**: só `h()` e `textContent` de `@comum/ui/dom`. Proibidos `innerHTML`, `outerHTML`, `insertAdjacentHTML` e atributos `on*=` em string. O build reprova.
- **JS gerado só ASCII** (`charset: "ascii"` no esbuild). Acentos em strings de código viram `\uXXXX` na saída do esbuild; no **fonte** `.ts` podem ser caracteres normais. O portão de bytes do build confere. Para `dist/js/background.js` (edição à mão, D14) os acentos têm que ser `\uXXXX` escritos à mão, e a conferência é por bytes (`perl -ne 'print if /[\x80-\xff]/'`), nunca por `grep` BSD.
- **Nunca buscar a árvore do processo** nem os endereços `procedimento_visualizar`, `arvore_montar`, `procedimento_atribuicao_cadastrar` no que roda no SEI (grava "Processo recebido" em nome do usuário). O build reprova.
- **Nunca montar URL do SEI**: usar links colhidos da página (`@nucleo/links/links`).
- **Sigiloso**: número de processo ou de documento sigiloso nunca vai ao Texto Padrão; o vínculo vai `{ protocolo: "", sigiloso: true }` e o documento `{ numero: "", sigiloso: true }`. O arquivo JSON do próprio usuário leva os números.
- **Modais**: `<dialog class="spro-dialogo">` via `criarAbrirModal`; **sem botão Cancelar** (o X e o Esc fecham).
- Datas civis são `DataISO` ("AAAA-MM-DD", fuso local); nunca `toISOString()` para data civil. Ordenação por índice fracionário (`@comum/ordem/indice`), comparado com `<` e `>`, nunca `localeCompare`.
- Teto de cada Texto Padrão: `TETO_TEXTO = 100 * 1024`, `AVISO_TEXTO = 80 * 1024` (bytes do HTML). Aviso do arquivo local: 5 MB. Aviso de peso total dos três textos: 200 KB. Aviso de desempenho: mais de 800 demandas ativas.
- Lápides: 180 dias (escopo `unidade`), 90 dias (escopo `eu`). Carimbo mais de 1 dia no futuro é recusado (`FOLGA_RELOGIO_MS`).
- **Sem permissão nova** no manifest; **só o `dist/manifest.json` (Lab MV3)** recebe o módulo. Não mexer em `manifest_seipro*.json`, `manifest_v2.json` nem nos whitelabels.
- Nunca `git add -A` nem `git clean -fd`; sempre `git add` com caminhos explícitos. Push, merge e release só com o autor.
- Trabalhar numa **worktree** (`../sei-pro-demandas`, branch `feat/demandas-ts`); o repositório está no iCloud (apagar e recriar gera cópias "nome 2.ext"; limpar antes de empacotar).
- Fim de todo commit: a linha `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` (como consta na atribuição da sessão).

## Review Focus

As entradas que o spec implica e nenhuma tarefa exercita sozinha; cada linha tem o teste na tarefa dona do código (indicada entre colchetes):

1. **Texto Padrão editado à mão, vazio ou de versão mais nova** não pode apagar dados locais nem ser sobrescrito às cegas [D6].
2. **Uma tabela grande demais (histórico) não bloqueia as outras** (as demandas continuam sincronizando) [D6].
3. **Demanda arquivada por um colega** que ainda aparece como não arquivada num texto velho: a versão arquivada vence e a demanda sai da tabela `d` sem lápide [D4, D5].
4. **Relógio adiantado de um colega** (carimbo 2 dias no futuro) não vence toda edição para sempre [D4].
5. **Arquivo JSON alterado por outro computador** entre a leitura e a gravação não é sobrescrito [D6].
6. **Processo sigiloso vinculado**: o número some do texto e **volta** na mesclagem a quem o tem (não é perdido na volta) [D4, D5].
7. **Quadro**: arrastar para coluna inválida devolve o cartão; cancelar o diálogo de concluir/avaliar não grava nada [D9].
8. **Troca de unidade ou de usuário** no SEI com o painel aberto não grava na unidade antiga [D13].
9. **Limite**: criação bloqueada a 100% do texto `d`; editar, concluir e arquivar continuam [D8, D12].
10. **Prazo com data inválida** ("2026-02-30"), título vazio ou gigante, checklist com 51 itens: recusados com mensagem, nunca gravados [D1, D4].

export type SituacaoBase = "nao_iniciada" | "iniciada" | "pausada" | "concluida" | "avaliada";
export type Situacao = SituacaoBase | "arquivada";
export type EstadoPrazo = "no_prazo" | "atrasada" | "concluida_no_prazo" | "concluida_fora_do_prazo";

type CamposDeEstado = Pick<Demanda, "avaliacao" | "concluidaEm" | "pausas" | "iniciadaEm">;

/** O estado sem olhar o arquivamento (o que a demanda volta a ser ao desarquivar). */
export function situacaoBase(d: CamposDeEstado): SituacaoBase {
  if (d.avaliacao) return "avaliada";
  if (d.concluidaEm) return "concluida";
  const ultima = d.pausas[d.pausas.length - 1];
  if (ultima && ultima.fim === undefined) return "pausada";
  if (d.iniciadaEm !== undefined) return "iniciada";
  return "nao_iniciada";
}

export function situacaoDe(d: CamposDeEstado & Pick<Demanda, "arquivadoEm">): Situacao {
  return d.arquivadoEm !== undefined ? "arquivada" : situacaoBase(d);
}

/** Datas ISO comparam como texto. */
export function prazoDe(d: Pick<Demanda, "prazo" | "concluidaEm">, hoje: DataISO): EstadoPrazo {
  if (d.concluidaEm) return d.concluidaEm <= d.prazo ? "concluida_no_prazo" : "concluida_fora_do_prazo";
  return d.prazo < hoje ? "atrasada" : "no_prazo";
}

export function diasDeAtraso(d: Pick<Demanda, "prazo" | "concluidaEm">, hoje: DataISO): number {
  return prazoDe(d, hoje) === "atrasada" ? diferencaDias(d.prazo, hoje) : 0;
}

/** Validação e limpeza dos campos da demanda (spec 3 e 4.3). Só devolve texto de problema; quem grava decide. */

import { type DataISO, deISO, hojeISO } from "@comum/datas/dias";
import { LIMITES } from "./constantes";
import type { Demanda, ItemChecklist } from "./tipos";

export class ErroValidacao extends Error {
  constructor(
    readonly campo: string,
    mensagem: string,
  ) {
    super(mensagem);
    this.name = "ErroValidacao";
  }
}

const RE_DATA = /^\d{4}-\d{2}-\d{2}$/;

export function dataValida(x: unknown): x is DataISO {
  if (typeof x !== "string" || !RE_DATA.test(x)) return false;
  try {
    return hojeISO(deISO(x)) === x;
  } catch {
    return false;
  }
}

export const RE_ID = /^[A-Za-z0-9_-]{1,64}$/;
export const idValido = (x: unknown): x is string => typeof x === "string" && RE_ID.test(x);

export const textoAte = (max: number) => (x: unknown): x is string => typeof x === "string" && x.length <= max;

/** Corta, tira vazias e repetidas (sem olhar a caixa) e limita a quantidade. */
export function etiquetasLimpas(lista: readonly string[]): string[] {
  const vistas = new Set<string>();
  const saida: string[] = [];
  for (const bruta of lista) {
    const e = bruta.trim().slice(0, LIMITES.etiquetaTexto);
    const k = e.toLocaleLowerCase("pt-BR");
    if (!e || vistas.has(k)) continue;
    vistas.add(k);
    saida.push(e);
    if (saida.length === LIMITES.etiquetas) break;
  }
  return saida;
}

export function checklistLimpo(itens: readonly ItemChecklist[]): ItemChecklist[] {
  return itens
    .map((i) => ({ ...i, texto: i.texto.trim().slice(0, LIMITES.checklistTexto) }))
    .filter((i) => i.texto)
    .slice(0, LIMITES.checklistItens);
}

const PRIORIDADES = new Set(["normal", "importante", "urgente"]);
const tempoOk = (x: unknown) => x === undefined || (typeof x === "number" && Number.isInteger(x) && x >= 0 && x <= LIMITES.tempoMin);

/** Cada problema é "campo: mensagem". Vazio = a demanda é gravável. */
export function problemasDaDemanda(d: Pick<Demanda, "titulo" | "prazo" | "distribuidaEm"> & Partial<Demanda>): string[] {
  const p: string[] = [];
  if (typeof d.titulo !== "string" || !d.titulo.trim()) p.push("titulo: informe o título");
  else if (d.titulo.length > LIMITES.titulo) p.push(`titulo: passa de ${LIMITES.titulo} caracteres`);
  if (d.descricao !== undefined && !textoAte(LIMITES.descricao)(d.descricao)) p.push(`descricao: passa de ${LIMITES.descricao} caracteres`);
  if (!dataValida(d.distribuidaEm)) p.push("distribuidaEm: data inválida");
  if (!dataValida(d.prazo)) p.push("prazo: data inválida");
  else if (dataValida(d.distribuidaEm) && d.prazo < d.distribuidaEm) p.push("prazo: não pode ser antes da distribuição");
  if (d.prioridade !== undefined && !PRIORIDADES.has(d.prioridade)) p.push("prioridade: valor inválido");
  if ((d.etiquetas?.length ?? 0) > LIMITES.etiquetas) p.push(`etiquetas: no máximo ${LIMITES.etiquetas}`);
  if ((d.processos?.length ?? 0) > LIMITES.processos) p.push(`processos: no máximo ${LIMITES.processos}`);
  if ((d.checklist?.length ?? 0) > LIMITES.checklistItens) p.push(`checklist: no máximo ${LIMITES.checklistItens} itens`);
  if ((d.pausas?.length ?? 0) > LIMITES.pausas) p.push(`pausas: no máximo ${LIMITES.pausas}`);
  if (!tempoOk(d.tempoEstimadoMin)) p.push("tempoEstimadoMin: minutos inteiros e positivos");
  if (!tempoOk(d.tempoGastoMin)) p.push("tempoGastoMin: minutos inteiros e positivos");
  if (d.observacaoConclusao !== undefined && !textoAte(LIMITES.observacao)(d.observacaoConclusao))
    p.push(`observacaoConclusao: passa de ${LIMITES.observacao} caracteres`);
  return p;
}

export function conferirDemanda(d: Pick<Demanda, "titulo" | "prazo" | "distribuidaEm"> & Partial<Demanda>): void {
  const p = problemasDaDemanda(d)[0];
  if (!p) return;
  const i = p.indexOf(": ");
  throw new ErroValidacao(p.slice(0, i), p.slice(i + 2));
}

 * Transições do ciclo de vida (spec 3.2), puras: devolvem a demanda nova e os registros do histórico, ou lançam
 * `ErroOperacao`. Quem grava (o repositório) carimba o histórico com id, quando e quem.

import { LIMITES } from "./constantes";
import { type Situacao, situacaoBase, situacaoDe } from "./situacao";
import type { Carimbo, CampoHistorico, DataISO, Demanda, DocumentoSei } from "./tipos";
import { dataValida } from "./validacao";

export type CodigoErro = "transicao_invalida" | "dados_invalidos";

export class ErroOperacao extends Error {
  constructor(
    readonly codigo: CodigoErro,
    mensagem: string,
  ) {
    super(mensagem);
    this.name = "ErroOperacao";
  }
}

export interface RegistroNovo {
  demanda: string;
  campo: CampoHistorico;
  antes?: string;
  depois?: string;
  motivo?: string;
}

export interface Resultado {
  demanda: Demanda;
  registros: RegistroNovo[];
}

export interface DadosConclusao {
  data: DataISO;
  tempoGastoMin?: number;
  observacao?: string;
  documento?: DocumentoSei;
}
export interface DadosAvaliacao {
  nota: 1 | 2 | 3 | 4 | 5;
  comentario?: string;
}
export interface DadosProrrogacao {

export interface DadosMovimento {

const transicao = (msg: string) => new ErroOperacao("transicao_invalida", msg);
const dados = (msg: string) => new ErroOperacao("dados_invalidos", msg);

/** A demanda com o carimbo da gravação; `tirar` remove campos opcionais. */
function carimbar(d: Demanda, c: Carimbo, mudar: Partial<Demanda>, tirar: ReadonlyArray<keyof Demanda> = []): Demanda {
  const r = { ...d, ...mudar, atualizadoEm: c.agora, dispositivo: c.dispositivo } as Record<string, unknown>;
  if (c.por) r.alteradoPor = c.por;
  for (const k of tirar) delete r[k as string];
  return r as unknown as Demanda;
}

function exigir(d: Demanda, ok: (b: ReturnType<typeof situacaoBase>) => boolean, msg: string): void {
  if (d.arquivadoEm !== undefined) throw transicao("A demanda está arquivada. Desarquive antes.");
  if (!ok(situacaoBase(d))) throw transicao(msg);
}

const registro = (d: Demanda, campo: CampoHistorico, extra: Partial<RegistroNovo> = {}): RegistroNovo => ({ demanda: d.id, campo, ...extra });

export function iniciar(d: Demanda, c: Carimbo): Resultado {
  exigir(d, (s) => s === "nao_iniciada", "Só uma demanda não iniciada pode ser iniciada.");
  return { demanda: carimbar(d, c, { iniciadaEm: c.agora }), registros: [registro(d, "inicio", { depois: "iniciada" })] };
}

export function voltarANaoIniciada(d: Demanda, c: Carimbo): Resultado {
  exigir(d, (s) => s === "iniciada", "Só uma demanda iniciada volta a não iniciada.");
  return { demanda: carimbar(d, c, { pausas: [] }, ["iniciadaEm"]), registros: [registro(d, "inicio", { antes: "iniciada", depois: "não iniciada" })] };
}

export function pausar(d: Demanda, c: Carimbo): Resultado {
  exigir(d, (s) => s === "iniciada", "Só uma demanda iniciada pode ser pausada.");
  if (d.pausas.length >= LIMITES.pausas) throw dados(`Uma demanda aceita até ${LIMITES.pausas} pausas.`);
  return { demanda: carimbar(d, c, { pausas: [...d.pausas, { inicio: c.agora }] }), registros: [registro(d, "pausa")] };
}

const fecharPausa = (d: Demanda, agora: number): Demanda["pausas"] =>
  d.pausas.map((p, i) => (i === d.pausas.length - 1 && p.fim === undefined ? { ...p, fim: agora } : p));

export function retomar(d: Demanda, c: Carimbo): Resultado {
  exigir(d, (s) => s === "pausada", "Só uma demanda pausada pode ser retomada.");
  return { demanda: carimbar(d, c, { pausas: fecharPausa(d, c.agora) }), registros: [registro(d, "retomada")] };
}

export function concluir(d: Demanda, x: DadosConclusao, c: Carimbo): Resultado {
  exigir(d, (s) => s === "iniciada" || s === "pausada", "Só uma demanda iniciada ou pausada pode ser concluída.");
  if (!dataValida(x.data)) throw dados("Data de conclusão inválida.");
  if (x.data < d.distribuidaEm) throw dados("A conclusão não pode ser antes da distribuição.");
  const t = x.tempoGastoMin;
  if (t !== undefined && !(Number.isInteger(t) && t >= 0 && t <= LIMITES.tempoMin)) throw dados("Tempo gasto inválido (minutos inteiros e positivos).");
  const obs = x.observacao?.trim();
  if (obs && obs.length > LIMITES.observacao) throw dados(`A observação passa de ${LIMITES.observacao} caracteres.`);
  const mudar: Partial<Demanda> = { concluidaEm: x.data, pausas: fecharPausa(d, c.agora) };
  if (t !== undefined) mudar.tempoGastoMin = t;
  if (obs) mudar.observacaoConclusao = obs;
  if (x.documento) mudar.documentoEntregue = x.documento;
  return { demanda: carimbar(d, c, mudar), registros: [registro(d, "conclusao", { depois: x.data })] };
}

export function reabrir(d: Demanda, c: Carimbo): Resultado {
  exigir(d, (s) => s === "concluida", "Só uma demanda concluída (e não avaliada) pode ser reaberta.");
  return {
    demanda: carimbar(d, c, {}, ["concluidaEm", "tempoGastoMin", "observacaoConclusao", "documentoEntregue"]),
    registros: [registro(d, "reabertura", { antes: d.concluidaEm })],
  };
}

export function avaliar(d: Demanda, x: DadosAvaliacao, c: Carimbo): Resultado {
  exigir(d, (s) => s === "concluida", "Só uma demanda concluída pode ser avaliada.");
  if (![1, 2, 3, 4, 5].includes(x.nota)) throw dados("A nota vai de 1 a 5.");
  const comentario = x.comentario?.trim();
  if (comentario && comentario.length > LIMITES.comentario) throw dados(`O comentário passa de ${LIMITES.comentario} caracteres.`);
  const avaliacao = { nota: x.nota, ...(comentario ? { comentario } : {}), por: c.por ?? "", em: c.agora };
  return { demanda: carimbar(d, c, { avaliacao }), registros: [registro(d, "avaliacao", { depois: String(x.nota) })] };
}

export function cancelarAvaliacao(d: Demanda, c: Carimbo): Resultado {
  exigir(d, (s) => s === "avaliada", "Só uma demanda avaliada tem avaliação a cancelar.");
  return { demanda: carimbar(d, c, {}, ["avaliacao"]), registros: [registro(d, "avaliacao", { antes: String(d.avaliacao?.nota ?? ""), depois: "" })] };
}

export function arquivar(d: Demanda, c: Carimbo): Resultado {
  exigir(d, (s) => s === "concluida" || s === "avaliada", "Só uma demanda concluída ou avaliada pode ser arquivada.");
  return { demanda: carimbar(d, c, { arquivadoEm: c.agora }), registros: [registro(d, "arquivamento")] };
}

export function desarquivar(d: Demanda, c: Carimbo): Resultado {
  if (d.arquivadoEm === undefined) throw transicao("A demanda não está arquivada.");
  return { demanda: carimbar(d, c, {}, ["arquivadoEm"]), registros: [registro(d, "desarquivamento")] };
}

export function prorrogar(d: Demanda, x: DadosProrrogacao, c: Carimbo): Resultado {
  exigir(d, (s) => s === "nao_iniciada" || s === "iniciada" || s === "pausada", "Só uma demanda em andamento tem prazo a prorrogar.");
  const motivo = x.motivo.trim();
  if (!motivo) throw dados("Informe o motivo da mudança de prazo.");
  if (motivo.length > LIMITES.motivo) throw dados(`O motivo passa de ${LIMITES.motivo} caracteres.`);
  if (!dataValida(x.prazo)) throw dados("Prazo inválido.");
  if (x.prazo === d.prazo) throw dados("O novo prazo é igual ao atual.");
  if (x.prazo < d.distribuidaEm) throw dados("O prazo não pode ser antes da distribuição.");
  return {
    demanda: carimbar(d, c, { prazo: x.prazo, prazoOriginal: d.prazoOriginal ?? d.prazo }),
    registros: [registro(d, "prazo", { antes: d.prazo, depois: x.prazo, motivo })],
  };
}

type Chave = `${Situacao}>${Situacao}`;
const MATRIZ: ReadonlyMap<Chave, "conclusao" | "avaliacao" | null> = new Map<Chave, "conclusao" | "avaliacao" | null>([
  ["nao_iniciada>iniciada", null],
  ["iniciada>nao_iniciada", null],
  ["iniciada>pausada", null],
  ["pausada>iniciada", null],
  ["iniciada>concluida", "conclusao"],
  ["pausada>concluida", "conclusao"],
  ["concluida>iniciada", null],
  ["concluida>avaliada", "avaliacao"],
  ["avaliada>concluida", null],
  ["concluida>arquivada", null],
  ["avaliada>arquivada", null],
  ["arquivada>concluida", null],
  ["arquivada>avaliada", null],
]);

export const movimentoPermitido = (de: Situacao, para: Situacao): boolean => MATRIZ.has(`${de}>${para}`);

/** O que o diálogo precisa coletar antes de o movimento ser aplicado (null: nada). */
export function dadosQueOMovimentoPede(de: Situacao, para: Situacao): "conclusao" | "avaliacao" | null {
  return MATRIZ.get(`${de}>${para}`) ?? null;
}

export function moverPara(d: Demanda, destino: Situacao, x: DadosMovimento, c: Carimbo): Resultado {
  const de = situacaoDe(d);
  if (!movimentoPermitido(de, destino)) throw transicao("Esse movimento não é permitido.");
  switch (`${de}>${destino}` as Chave) {
    case "nao_iniciada>iniciada":
      return iniciar(d, c);
    case "iniciada>nao_iniciada":
      return voltarANaoIniciada(d, c);
    case "iniciada>pausada":
      return pausar(d, c);
    case "pausada>iniciada":
      return retomar(d, c);
    case "iniciada>concluida":
    case "pausada>concluida":
      if (!x.conclusao) throw dados("Faltam os dados da conclusão.");
      return concluir(d, x.conclusao, c);
    case "concluida>iniciada":
      return reabrir(d, c);
    case "concluida>avaliada":
      if (!x.avaliacao) throw dados("Faltam os dados da avaliação.");
      return avaliar(d, x.avaliacao, c);
    case "avaliada>concluida":
      return cancelarAvaliacao(d, c);
    case "concluida>arquivada":
    case "avaliada>arquivada":
      return arquivar(d, c);
    default: {
      // arquivada>concluida | arquivada>avaliada: desarquivar só vale se o destino é o estado de antes.
      if (situacaoBase(d) !== destino) throw transicao("A demanda volta ao estado de antes de ser arquivada.");
      return desarquivar(d, c);
    }
  }
}

import { AVISO_ATIVAS, AVISO_PESO_TOTAL, AVISO_TEXTO, TETO_TEXTO } from "./constantes";

export type Faixa = "normal" | "aviso" | "bloqueio";

export function faixaDoTamanho(bytes: number | undefined, teto = TETO_TEXTO, aviso = AVISO_TEXTO): { faixa: Faixa; percentual: number } {
  if (bytes === undefined) return { faixa: "normal", percentual: 0 };
  const percentual = Math.round((bytes / teto) * 100);
  if (bytes >= teto) return { faixa: "bloqueio", percentual };
  if (bytes >= aviso) return { faixa: "aviso", percentual };
  return { faixa: "normal", percentual };
}

  if (!r) return SEM_RESPONSAVEL;
  return r.login ? `l:${r.login.trim().toLowerCase()}` : `n:${normalizarTexto(r.nome)}`;
}

export function filtrar(
  lista: readonly Demanda[],
  f: FiltroDemandas,
  ctx: { hoje: DataISO; eu: Responsavel },
): Demanda[] {
  const minha = chaveResponsavel(ctx.eu);
  const resp = f.responsaveis?.map((r) => (r === EU ? minha : r));
  const busca = f.busca ? normalizarTexto(f.busca) : "";
  const semana = somarDias(ctx.hoje, 7);
  const mes = somarDias(ctx.hoje, 30);
  return lista.filter((d) => {
    const s = situacaoDe(d);
    if (s === "arquivada" && !f.mostrarArquivadas) return false;
    if (resp?.length && !resp.includes(chaveResponsavel(d.responsavel))) return false;
    if (f.situacoes?.length && !f.situacoes.includes(s)) return false;
    if (f.prazo === "atrasadas" && prazoDe(d, ctx.hoje) !== "atrasada") return false;
    if (f.prazo === "semana" && !(d.prazo >= ctx.hoje && d.prazo <= semana && !d.concluidaEm)) return false;
    if (f.prazo === "mes" && !(d.prazo >= ctx.hoje && d.prazo <= mes && !d.concluidaEm)) return false;
    if (f.prioridades?.length && !f.prioridades.includes(d.prioridade)) return false;
    if (f.etiquetas?.length) {
      const dele = d.etiquetas.map((e) => e.toLocaleLowerCase("pt-BR"));
      if (!f.etiquetas.some((e) => dele.includes(e.toLocaleLowerCase("pt-BR")))) return false;
    }
    if (f.etapa && d.etapa?.etapa !== f.etapa) return false;
    if (busca) {
      const palheiro = normalizarTexto([d.titulo, d.descricao ?? "", ...d.processos.map((p) => p.protocolo), ...d.etiquetas].join(" "));
      if (!palheiro.includes(busca)) return false;
    }
    return true;
  });
}

/** Números do painel (spec 5.5). Puro: recebe as demandas e devolve tudo calculado. */

import { type DataISO, diferencaDias } from "@comum/datas/dias";
import { chaveResponsavel } from "./filtro";
import { diasDeAtraso, prazoDe, type Situacao, situacaoDe } from "./situacao";
import type { Demanda } from "./tipos";

export interface LinhaAtrasada {
  id: string;
  titulo: string;
  diasAtraso: number;
  responsavel?: Demanda["responsavel"];
}
export interface CargaResponsavel {
  chave: string;
  nome: string;
  abertas: number;
  atrasadas: number;
  concluidas: number;
}
export interface Estatisticas {
  porSituacao: Record<Situacao, number>;
  atrasadas: LinhaAtrasada[];
  cargaPorResponsavel: CargaResponsavel[];
  entregasPorMes: Array<{ mes: string; noPrazo: number; foraDoPrazo: number }>;
  prazoMedioDias: number | null;
  percentualNoPrazo: number | null;
  estimadoMin: number;
  gastoMin: number;
  desvioMedioMin: number | null;
  notaMedia: number | null;
  distribuicaoNotas: [number, number, number, number, number];
}

export function calcularEstatisticas(lista: readonly Demanda[], o: { hoje: DataISO; desde?: DataISO }): Estatisticas {
  const porSituacao: Record<Situacao, number> = { nao_iniciada: 0, iniciada: 0, pausada: 0, concluida: 0, avaliada: 0, arquivada: 0 };
  const atrasadas: LinhaAtrasada[] = [];
  const carga = new Map<string, CargaResponsavel>();
  const meses = new Map<string, { noPrazo: number; foraDoPrazo: number }>();
  const notas: [number, number, number, number, number] = [0, 0, 0, 0, 0];
  let somaDias = 0;
  let nConcluidas = 0;
  let noPrazo = 0;
  let estimado = 0;
  let gasto = 0;
  let desvio = 0;
  let nDesvio = 0;
  let somaNotas = 0;
  let nNotas = 0;

  for (const d of lista) {
    const s = situacaoDe(d);
    // Período corta o que foi concluído antes dele; o que está aberto sempre entra.
    if (d.concluidaEm && o.desde && d.concluidaEm < o.desde) continue;
    porSituacao[s] += 1;
    const chave = chaveResponsavel(d.responsavel);
    const c = carga.get(chave) ?? { chave, nome: d.responsavel?.nome ?? "Sem responsável", abertas: 0, atrasadas: 0, concluidas: 0 };
    carga.set(chave, c);
    if (d.concluidaEm) {
      c.concluidas += 1;
      nConcluidas += 1;
      somaDias += diferencaDias(d.distribuidaEm, d.concluidaEm);
      const no = prazoDe(d, o.hoje) === "concluida_no_prazo";
      if (no) noPrazo += 1;
      const mes = d.concluidaEm.slice(0, 7);
      const m = meses.get(mes) ?? { noPrazo: 0, foraDoPrazo: 0 };
      if (no) m.noPrazo += 1;
      else m.foraDoPrazo += 1;
      meses.set(mes, m);
      if (d.tempoEstimadoMin !== undefined && d.tempoGastoMin !== undefined) {
        estimado += d.tempoEstimadoMin;
        gasto += d.tempoGastoMin;
        desvio += d.tempoGastoMin - d.tempoEstimadoMin;
        nDesvio += 1;
      }
    } else if (s !== "arquivada") {
      c.abertas += 1;
      if (prazoDe(d, o.hoje) === "atrasada") {
        c.atrasadas += 1;
        atrasadas.push({ id: d.id, titulo: d.titulo, diasAtraso: diasDeAtraso(d, o.hoje), ...(d.responsavel ? { responsavel: d.responsavel } : {}) });
      }
    }
    if (d.avaliacao) {
      notas[d.avaliacao.nota - 1] = (notas[d.avaliacao.nota - 1] ?? 0) + 1;
      somaNotas += d.avaliacao.nota;
      nNotas += 1;
    }
  }

  return {
    porSituacao,
    atrasadas: atrasadas.sort((a, b) => b.diasAtraso - a.diasAtraso || (a.id < b.id ? -1 : 1)),
    cargaPorResponsavel: [...carga.values()].sort((a, b) => b.abertas - a.abertas || a.nome.localeCompare(b.nome, "pt-BR")),
    entregasPorMes: [...meses.entries()].sort(([a], [b]) => (a < b ? -1 : 1)).map(([mes, v]) => ({ mes, ...v })),
    prazoMedioDias: nConcluidas ? somaDias / nConcluidas : null,
    percentualNoPrazo: nConcluidas ? Math.round((noPrazo / nConcluidas) * 100) : null,
    estimadoMin: estimado,
    gastoMin: gasto,
    desvioMedioMin: nDesvio ? desvio / nDesvio : null,
    notaMedia: nNotas ? somaNotas / nNotas : null,
    distribuicaoNotas: notas,
  };
}

  async importar(ent: Partial<Entidades>, agora: number = Date.now()): Promise<ResultadoImportacao> {

    const local = await this.entidades();
    const porId = new Map(local.d.map((x) => [x.id, x]));

    const gravar: Demanda[] = [];
    for (const x of ent.d ?? []) {
      if (!entidadeValida(x, "d", agora)) {
        r.ignorados += 1;
        continue;
      }
      const atual = porId.get(x.id);
      if (atual && !vence(x, atual)) continue;
      const ehAtiva = vivo(x) && x.arquivadoEm === undefined;
      const eraAtiva = !!atual && vivo(atual) && atual.arquivadoEm === undefined;
      if (ehAtiva && !eraAtiva && ativas >= LIMITES.ativas) {
        r.ignorados += 1;
        r.excedentes += 1;
        continue;
      }
      if (ehAtiva && !eraAtiva) ativas += 1;
      gravar.push(manterNumerosSigilosos(x, atual));
      if (atual) r.atualizados += 1;
      else r.novos += 1;
    }
    const locaisH = new Map(local.h.map((x) => [x.id, x]));
    const gravarH: Registro[] = [];
    for (const x of ent.h ?? []) {
      if (!entidadeValida(x, "h", agora)) {
        r.ignorados += 1;
        continue;
      }
      const atual = locaisH.get(x.id);
      if (!atual || vence(x, atual)) {
        gravarH.push(x);
        if (atual) r.atualizados += 1;
        else r.novos += 1;
      }
    }
    if (gravar.length || gravarH.length)
      await this.area.gravar({
        ...Object.fromEntries(gravar.map((d) => [this.demandas.chave(d.id), d])),
        ...Object.fromEntries(gravarH.map((h) => [this.registros.chave(h.id), h])),

    return r;

  /** O envelope de uma tabela, podado (lápides vencidas; histórico nos mais recentes). Sem o corte do sigilo (adaptador). */

    const dias = diasDeLapide(this.escopo.vis);
    const entidades: Entidades =
      tabela === "h"
        ? {
            d: [],
            h: purgarLapides(ent.h, agora, dias)
              .sort((a, b) => b.quando - a.quando || (a.id < b.id ? 1 : -1))
              .slice(0, LIMITES.historicoNoTexto),
          }
        : { d: purgarLapides(ent.d, agora, dias).filter((x) => (x.arquivadoEm !== undefined) === (tabela === "a")), h: [] };
    return {
      formato: "seipro-demandas",
      versao: 1,
      tabela,
      host: this.escopo.host,
      unidade: this.escopo.unidade,
      vis: this.escopo.vis,
      ...(this.escopo.vis === "eu" ? { login: this.escopo.login.trim().toLowerCase() } : {}),
      gerado: agora,
      entidades,
    };
  }

    const memoria = lerMemoria(await this.lerChaves(false), this.prefixoMemoria);
    const e = entradasParaGravar(memoria, novos, origem, this.prefixoMemoria, o);
    if (Object.keys(e).length) await this.area.gravar(e);
  }

  /**
   * O envelope da tabela e o que a memória do sigilo sabe, numa leitura só: o que raspa é o estado que vai.
   * Lança se a memória não puder ser lida.
   */
  async exportarComConhecidos(tabela: Tabela, agora: number = Date.now()): Promise<{ envelope: EnvelopeDemandas; conhecidos: SigilosConhecidos }> {
    const tudo = await this.lerChaves(true);
    return { envelope: this.envelopeDe(this.entidadesDe(tudo), tabela, agora), conhecidos: conhecidosDe(lerMemoria(tudo, this.prefixoMemoria)) };
  }

  /**
   * O processo é sigiloso (a árvore ou a caixa o mostram assim): marca os vínculos locais que o têm (SEM mudar o
   * carimbo: todo computador que conhece o número chega à mesma marca) e o lembra como local. Devolve quantas
   * demandas foram marcadas.
   */
  async marcarSigilosos(protocolos: readonly string[]): Promise<number> {
    const chaves = new Set(protocolos.map(chaveProtocolo).filter(Boolean));
    if (!chaves.size) return 0;
    const marcadas: Demanda[] = [];
    for (const d of (await this.entidades()).d) {
      if (d.processos.some((p) => p.protocolo && chaves.has(chaveProtocolo(p.protocolo)) && !p.sigiloso))
        marcadas.push({ ...d, processos: d.processos.map((p) => (p.protocolo && chaves.has(chaveProtocolo(p.protocolo)) ? { ...p, sigiloso: true } : p)) });
    }
    await this.lembrarSigilo({ ...nenhumNumero(), processos: [...protocolos] }, "local", { promover: true });
    if (marcadas.length) await this.area.gravar(Object.fromEntries(marcadas.map((d) => [this.demandas.chave(d.id), d])));
    return marcadas.length;
  }
}

export function manterNumerosSigilosos(vencedor: Demanda, local?: Demanda): Demanda {
  if (!local) return vencedor;

/**
 * O corte do sigilo nas demandas (spec 4.6): processo ou documento sigiloso nunca vai ao Texto Padrão. A regra é
 * a do Projetos (`@projetos/modelo/sigilo`): vai vazio e marcado. O que o corte raspa volta como `raspados` para a
 * memória do sigilo do usuário (o que o texto raspou uma vez continua raspado).
 */

import { DOCUMENTO_VAZIO, nenhumNumero, type Numeros, type SigilosConhecidos, VINCULO_VAZIO } from "@projetos/modelo/sigilo";
import { chaveDocumento, chaveProtocolo } from "@projetos/modelo/vinculos";
import type { Demanda } from "./tipos";

export function cortarSigiloDemandas(demandas: readonly Demanda[], conhecidos: SigilosConhecidos): { demandas: Demanda[]; raspados: Numeros } {
  const raspados = nenhumNumero();
  const saida = demandas.map((d) => {
    let mudou = false;
    const processos = d.processos.map((p) => {
      const sigiloso = p.sigiloso === true || (p.protocolo !== "" && conhecidos.processos.has(chaveProtocolo(p.protocolo)));
      if (!sigiloso) return p;
      if (p.protocolo) raspados.processos.push(p.protocolo);
      mudou = true;
      return { ...VINCULO_VAZIO };
    });
    let documentoEntregue = d.documentoEntregue;
    const doc = d.documentoEntregue;
    if (doc && (doc.sigiloso === true || (doc.numero !== "" && conhecidos.documentos.has(chaveDocumento(doc.numero))))) {
      if (doc.numero) raspados.documentos.push(doc.numero);
      documentoEntregue = { ...DOCUMENTO_VAZIO };
      mudou = true;
    }
    return mudou ? { ...d, processos, ...(documentoEntregue ? { documentoEntregue } : {}) } : d;
  });
  return { demandas: saida, raspados };
}

export function legivelDemandas(vis: Vis, tabela: Tabela, sigla: string, nomeUsuario: string): string {

export function validarEnvelope(bruto: unknown, escopo: Escopo, tabela: Tabela): ValidacaoTexto<EnvelopeDemandas> {
  if (versaoMaisNova(bruto, FORMATO, VERSAO)) return { maisNovo: true };
  const b = bruto as Partial<EnvelopeDemandas> | null;
  if (!b || typeof b !== "object" || b.formato !== FORMATO || b.versao !== VERSAO) return { invalido: "o texto não está no formato das demandas" };
  if (b.tabela !== tabela) return { invalido: "o texto é de outra tabela" };
  if (b.host !== escopo.host || String(b.unidade) !== escopo.unidade || b.vis !== escopo.vis)
    return { invalido: "o texto é de outro SEI, de outra unidade ou de outra visibilidade" };
  if (escopo.vis === "eu" && (typeof b.login !== "string" || b.login.trim().toLowerCase() !== escopo.login.trim().toLowerCase()))
    return { invalido: "o texto é de outro usuário" };
  const ent = b.entidades as Partial<Record<"d" | "h", unknown>> | undefined;
  if (!ent || typeof ent !== "object") return { invalido: "o texto não tem as demandas" };
  const d = ent.d ?? [];
  const h = ent.h ?? [];
  if (!Array.isArray(d) || !Array.isArray(h)) return { invalido: "o texto não tem as demandas" };
  if ((tabela === "h" ? h : d).length > TETOS_ENVELOPE[tabela]) return { invalido: "o texto tem itens demais" };
  return { ok: { ...(b as EnvelopeDemandas), entidades: { d: d as Demanda[], h: h as Registro[] } } };
}

/** O envelope que vai ao texto: sem números sigilosos. `raspados` é o que o corte tirou (vai para a memória do sigilo). */
export function paraOTexto(env: EnvelopeDemandas, conhecidos: SigilosConhecidos): { envelope: EnvelopeDemandas; raspados: Numeros } {
  const corte = cortarSigiloDemandas(env.entidades.d, conhecidos);
  return { envelope: { ...env, entidades: { ...env.entidades, d: corte.demandas } }, raspados: corte.raspados };
}

/**
 * Do envelope daqui, os itens do texto que a importação recusou só por virem do futuro (carimbo além de agora + 1
 * dia), no lugar do daqui de mesmo id. Item torto (que nem sem o relógio passaria) não é levado.
 */
export function comOsDoFuturo(env: EnvelopeDemandas, remoto: EnvelopeDemandas | null, agora: number): EnvelopeDemandas {
  if (!remoto) return env;
  const lista = env.tabela === "h" ? "h" : "d";
  const futuros = (remoto.entidades[lista] as unknown[]).filter((x) => entidadeValida(x, lista) && !entidadeValida(x, lista, agora));
  if (!futuros.length) return env;
  const ids = new Set(futuros.map((x) => (x as { id: string }).id));
  const mantidos = (env.entidades[lista] as Array<{ id: string }>).filter((x) => !ids.has(x.id));
  return { ...env, entidades: { ...env.entidades, [lista]: [...mantidos, ...futuros] } as EnvelopeDemandas["entidades"] };
}

/**
 * O texto lido como este adaptador o gravaria se só tivesse ele (o que a importação recusa fica de fora; a poda e o
 * corte do sigilo valem): o "exportar(importado(lido))" que o motor compara, sem o consentimento, com o daqui.
 */
export async function textoComoGravado(lido: EnvelopeDemandas, escopo: Escopo, agora: number): Promise<EnvelopeDemandas> {
  const repo = new RepositorioDemandas(areaMemoria(), escopo, () => ({ agora, dispositivo: "normalizar" }));
  await repo.importar(lido.entidades, agora);
  const { envelope, conhecidos } = await repo.exportarComConhecidos(lido.tabela, agora);
  return paraOTexto(comOsDoFuturo(envelope, lido, agora), conhecidos).envelope;
}

/**
 * Arquivamento em massa e arquivo morto (spec 4.5). Nada aqui apaga: as candidatas só vão de `d` para `a` (D4:
 * `arquivarVarias`), e o descarte (lápide) só acontece depois de o usuário confirmar que guardou o arquivo.
 */

import { type DataISO, diferencaDias } from "@comum/datas/dias";
import { situacaoBase } from "../modelo/situacao";
import type { Demanda, Entidades, Escopo, Registro, Vis } from "../modelo/tipos";

export const FORMATO_ARQUIVO_MORTO = "seipro-demandas-arquivo";

export function candidatasAoArquivamento(demandas: readonly Demanda[], o: { hoje: DataISO; dias: number }): Demanda[] {
  return demandas.filter((d) => {
    if (d.removidoEm !== undefined || d.arquivadoEm !== undefined || !d.concluidaEm) return false;
    const s = situacaoBase(d);
    return (s === "concluida" || s === "avaliada") && diferencaDias(d.concluidaEm, o.hoje) > o.dias;
  });
}

export function estimarLiberacao(candidatas: readonly Demanda[]): { quantidade: number; bytes: number } {
  return { quantidade: candidatas.length, bytes: new TextEncoder().encode(JSON.stringify(candidatas)).length };
}

export interface ArquivoMorto {
  formato: typeof FORMATO_ARQUIVO_MORTO;
  versao: 1;
  host: string;
  unidade: string;
  vis: Vis;
  login: string;
  gerado: number;
  ate: DataISO;
  demandas: Demanda[];
  registros: Registro[];
}

export function montarArquivoMorto(ent: Entidades, escopo: Escopo, antesDe: DataISO, agora: number): ArquivoMorto {
  const demandas = ent.d.filter((d) => d.removidoEm === undefined && d.arquivadoEm !== undefined && d.concluidaEm !== undefined && d.concluidaEm < antesDe);
  const ids = new Set(demandas.map((d) => d.id));
  return {
    formato: FORMATO_ARQUIVO_MORTO,
    versao: 1,
    host: escopo.host,
    unidade: escopo.unidade,
    vis: escopo.vis,
    login: escopo.login.trim().toLowerCase(),
    gerado: agora,
    ate: antesDe,
    demandas,
    registros: ent.h.filter((r) => ids.has(r.demanda)),
  };
}

export const naTela = (demanda: Demanda, vis: Vis, hoje: DataISO): DemandaNaTela => ({
  demanda,

export async function carregarDados(repos: Readonly<Record<Vis, RepositorioDemandas>>, hoje: DataISO): Promise<DemandaNaTela[]> {

  );
}

export function responsaveisUsados(lista: readonly DemandaNaTela[]): UsuarioDaUnidade[] {

export function etiquetasUsadas(lista: readonly DemandaNaTela[]): string[] {
  const vistas = new Map<string, string>();
  for (const x of lista) for (const e of x.demanda.etiquetas) vistas.set(e.toLocaleLowerCase("pt-BR"), e);

export function lerTempo(texto: string): number | undefined | null {
  const t = texto.trim().toLowerCase().replace(/\s+/g, "");
  if (!t) return undefined;
  let m = /^(\d+)(?:h|:)(\d{1,2})(?:min)?$/.exec(t);
  if (m) return Number(m[1]) * 60 + Number(m[2]);
  m = /^(\d+)h$/.exec(t);
  if (m) return Number(m[1]) * 60;
  m = /^(\d+)(?:min)?$/.exec(t);
  if (m) return Number(m[1]);
  return null;
}

/** O quadro (spec 5.3): as colunas e o que o arrastar faz. Puro. */

import { type DataISO, diferencaDias } from "@comum/datas/dias";
import type { DemandaNaTela } from "../app/dados";
import { dadosQueOMovimentoPede, movimentoPermitido } from "./operacoes";
import type { Situacao } from "./situacao";
import { situacaoDe } from "./situacao";
import type { Demanda } from "./tipos";

export const COLUNAS_DO_QUADRO: readonly Situacao[] = ["nao_iniciada", "iniciada", "pausada", "concluida", "avaliada"];

export type PlanoMovimento = { tipo: "aplicar" } | { tipo: "pedir"; dados: "conclusao" | "avaliacao" } | { tipo: "recusar"; mensagem: string };

export function colunasDoQuadro(
  itens: readonly DemandaNaTela[],
  o: { hoje: DataISO; mostrarArquivadas: boolean; concluidasDias: number },
): Record<Situacao, DemandaNaTela[]> {
  const colunas: Record<Situacao, DemandaNaTela[]> = { nao_iniciada: [], iniciada: [], pausada: [], concluida: [], avaliada: [], arquivada: [] };
  for (const x of itens) {
    if (x.situacao === "arquivada" && !o.mostrarArquivadas) continue;
    const feita = x.situacao === "concluida" || x.situacao === "avaliada";
    // Concluídas e avaliadas só mostram os últimos N dias; o resto fica na Tabela e no filtro "Arquivadas".
    if (feita && x.demanda.concluidaEm && diferencaDias(x.demanda.concluidaEm, o.hoje) > o.concluidasDias) continue;
    colunas[x.situacao].push(x);
  }
  return colunas;
}

export function planoDoMovimento(d: Demanda, destino: Situacao): PlanoMovimento {
  const de = situacaoDe(d);
  if (de === destino) return { tipo: "recusar", mensagem: "" };
  if (!movimentoPermitido(de, destino)) return { tipo: "recusar", mensagem: "Esse movimento não é permitido. Use o menu da demanda." };
  const dados = dadosQueOMovimentoPede(de, destino);
  return dados ? { tipo: "pedir", dados } : { tipo: "aplicar" };
}

  const porId = new Map(o.itens.map((x) => [x.demanda.id, x]));
  let arrastando: string | null = null;
  const raiz = h("div", { class: "dem-quadro" });
  const lista: Situacao[] = [...COLUNAS_DO_QUADRO, ...(o.mostrarArquivadas ? (["arquivada"] as const) : [])];
  for (const s of lista) {
    const corpo = h("div", { class: "dem-coluna-corpo", "data-coluna": s });
    corpo.append(...colunas[s].map((x) => montarCartao(x, { aoClicar: (a) => o.aoClicar(x, a) })));
    corpo.addEventListener("dragover", (ev) => {
      if (!arrastando) return;
      ev.preventDefault(); // só quem tem drop liberado deixa soltar
    });
    corpo.addEventListener("drop", (ev) => {
      ev.preventDefault();
      const id = arrastando ?? (ev as DragEvent).dataTransfer?.getData("text/plain") ?? null;
      arrastando = null;
      const alvo = id ? porId.get(id) : undefined;
      if (!alvo) return;

      if (alvo.situacao === s) {

        const sobre = (ev.target as Element).closest<HTMLElement>(".dem-cartao")?.dataset.id ?? null;
        const i = sobre ? irmaos.findIndex((x) => x.demanda.id === sobre) : irmaos.length;
        void o.aoReordenar(alvo, irmaos[i - 1]?.demanda.id ?? null, irmaos[i]?.demanda.id ?? null);
        return;
      }
      void o.aoMover(alvo, s);
    });
    raiz.append(h("section", { class: "dem-coluna", "data-situacao": s }, h("header", {}, h("h3", {}, ROTULO[s]), h("span", { class: "dem-conta" }, String(colunas[s].length))), corpo));

  if (x.situacao === "concluida" || x.situacao === "avaliada" || x.situacao === "arquivada") return "concluida";
  if (x.prazo === "atrasada") return "atrasada";
  if (x.situacao === "iniciada" || x.situacao === "pausada") return "andamento";
  return "futura";
}

function progresso(x: DemandaNaTela): number {
  const d = x.demanda;
  if (d.concluidaEm) return 100;
  if (d.checklist.length) return Math.round((d.checklist.filter((i) => i.feito).length / d.checklist.length) * 100);
  return x.situacao === "iniciada" || x.situacao === "pausada" ? 50 : 0;
}

function etapaSintetica(x: DemandaNaTela): Etapa {
  const d = x.demanda;
  return {
    id: d.id, projeto: "demandas", ordem: d.ordem, nome: d.titulo,
    inicio: d.distribuidaEm, fim: d.prazo < d.distribuidaEm ? d.distribuidaEm : d.prazo,
    marco: false, dependeDe: [], medida: "checklist", progresso: 0, checklist: d.checklist, etiquetas: d.etiquetas,
    ...(d.responsavel ? { responsavel: d.responsavel } : {}),
    ...(d.concluidaEm ? { concluidaEm: d.concluidaEm } : {}),
    criadoEm: d.criadoEm, atualizadoEm: d.atualizadoEm, dispositivo: d.dispositivo,
  };
}

export function demandasComoLinhas(itens: readonly DemandaNaTela[], o: { hoje: DataISO; agrupar: "responsavel" | "situacao" }): Linha[] {
  const grupos = new Map<string, { nome: string; itens: DemandaNaTela[]; ordem: number }>();
  for (const x of itens) {
    const chave = o.agrupar === "responsavel" ? chaveResponsavel(x.demanda.responsavel) : x.situacao;
    const nome = o.agrupar === "responsavel" ? (x.demanda.responsavel?.nome ?? "Sem responsável") : ROTULO[x.situacao];
    const g = grupos.get(chave) ?? { nome, itens: [], ordem: o.agrupar === "situacao" ? ORDEM_SITUACAO.indexOf(x.situacao) : chave === "__sem__" ? 1 : 0 };
    g.itens.push(x);
    grupos.set(chave, g);
  }
  const ordenados = [...grupos.entries()].sort(([, a], [, b]) => a.ordem - b.ordem || a.nome.localeCompare(b.nome, "pt-BR"));
  const linhas: Linha[] = [];
  for (const [chave, g] of ordenados) {
    const etapas = g.itens.map(etapaSintetica);
    const resumo = resumoDeEtapas(etapas, o.hoje);
    const fase: Fase = { id: chave.replace(/[^A-Za-z0-9_-]/g, "_"), projeto: "demandas", nome: g.nome, ordem: "a0", atualizadoEm: 0, dispositivo: "" };
    const cabeca: LinhaFase = { tipo: "fase", id: idLinhaFase(fase.id), fase, resumo, recolhida: false, inicio: resumo.inicio ?? o.hoje, fim: resumo.fim ?? o.hoje };
    linhas.push(cabeca);
    for (const x of g.itens) {
      const e = etapaSintetica(x);
      linhas.push({ tipo: "etapa", id: x.demanda.id, etapa: e, situacao: situacaoDaLinha(x), progresso: progresso(x), dependeDe: [] });
    }
  }
  return linhas;
}
